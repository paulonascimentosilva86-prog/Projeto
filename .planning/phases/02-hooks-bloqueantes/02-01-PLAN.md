### Task 3: Refatorar validar-peticao.sh
Reescrever `claude-code-juridico/hooks/validar-peticao.sh`:

1. Manter a interface: recebe `$1` como caminho do arquivo
2. Arquivo vazio/inexistente → exit 1 com mensagem "[ERRO] Arquivo vazio ou inexistente"
3. Verificar 3 elementos essenciais (HOOK-01/02/03):
   - Endereçamento: `excelentissimo|exmo|meritissimo|juiz.*vara|tribunal|comarca|foro`
   - Qualificação: `(CPF|CNPJ|brasileiro|brasileira|nacionalidade|estado civil|portador)` (precisa match)
   - Pedidos: `dos pedidos|requer|ante o exposto|pede deferimento`
4. Cada elemento ausente → mensagem `[ERRO] Elemento essencial ausente: X`
5. Se qualquer elemento faltar → exit 1
6. Validação por tipo (HOOK-04):
   - Se conteúdo contém "condominial|cota condominial|condominio" → exigir "planilha|discrimina"
   - Se conteúdo contém "trabalhista|reclamacao trabalhista|reclamante" → exigir "verbas|FGTS|rescisoria|horas extras|salario"
   - Tipo ausente → `[ERRO] Validacao de tipo: X exige Y`
   - Tipo ausente → exit 1
7. Tudo presente → `[VALIDACAO] ✓ Peticao validada com sucesso` → exit 0
