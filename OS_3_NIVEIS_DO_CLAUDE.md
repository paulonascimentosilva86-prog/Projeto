## 01 — CHAT
**claude.ai / App Mobile / Grátis para começar**

`Nível Conversação`

### ⚙ COMO CONFIGURAR
1. Crie uma conta gratuita em **claude.ai** ou baixe o app mobile
2. Abra **Configurações → Memória** — adicione seu cargo, objetivos e preferências
3. Crie um **Projeto** por fluxo de trabalho com instruções e arquivos específicos
4. Defina o **estilo personalizado** e modelo padrão (Haiku / Sonnet / Opus)

### ★ PRINCIPAIS RECURSOS
- **Memória** — aprende seu cargo e preferências permanentemente
- **Projetos** — espaços de trabalho isolados com instruções específicas
- **Artefatos** — gera código, documentos, diagramas e apps inline
- **Análise de arquivos** — carrega PDFs, imagens, CSVs, planilhas

### → USE PARA
> Redigir conteúdo, e-mails e posts para redes sociais com a sua voz
> Resumir relatórios, artigos e transcrições de reuniões
> Analisar planilhas, dados e modelos financeiros

## 02 — COWORK
**Agente Desktop / $20/mês Plano Pro mínimo**

`Nível Fluxo de Trabalho`

### ⚙ COMO CONFIGURAR
1. Baixe o **app desktop do Claude** (Plano Pro, $20/mês)
2. Crie uma pasta de contexto: about-me.md, brand-voice.md, working-style.md
3. Escreva **Instruções Globais + de Pasta** (carregamento automático por sessão)
4. Conecte apps via **Configurações → Conectores** (50+ gratuitos)

### ★ PRINCIPAIS RECURSOS
- **Acesso ao sistema de arquivos** — lê e escreve nas suas pastas locais
- **50+ Conectores** — Slack, Drive, Notion, LinkedIn, Gmail
- **11 Plugins** — marketing, vendas, finanças, dados, jurídico
- **Tarefas Agendadas** — diário, semanal ou intervalos cron personalizados

### → USE PARA
> Briefings diários às 7h a partir de 200+ perfis de concorrentes
> Triagem do Slack por urgência entregue toda manhã
> Posts do LinkedIn ranqueados por engajamento com temas extraídos

## 03 — CODE
**Agente Terminal / Planos de $20-200/mês**

`Nível Sistema Operacional`

### ⚙ COMO CONFIGURAR
1. Instale: `npm i -g @anthropic-ai/claude-code`
2. Execute `claude /init` → gera o **CLAUDE.md** (200-500 linhas)
3. Defina o **modo de permissão**: Ask First, Auto Edit ou Bypass
4. Comece com `/plan` — pesquisa somente leitura antes de construir

### ★ PRINCIPAIS RECURSOS
- **CLAUDE.md** — contexto persistente do projeto, carrega automaticamente a cada sessão
- **Agentes paralelos** — agentes simultâneos para 5-10x de produtividade
- **Skills** — fluxos de trabalho em markdown acionados por um único comando slash
- **Servidores MCP** — Slack, Ahrefs, Notion, Figma, LinkedIn, CRM

### → USE PARA
> Construir funcionalidades e entregar código em produção de forma autônoma
> Prospecção, outreach, propostas e CRM direto do terminal
> 48 skills substituindo $600-1K/mês em SaaS. Economiza 15-20 hrs/semana.
